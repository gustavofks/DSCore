# DSCore
Custom game library frontend for Nintendo DSi, designed to work alongside TWiLight Menu++.

> Status: early development.

DSCore is the interface you see. TWiLight Menu++ stays installed as an invisible engine that boots the
system and launches games through nds-bootstrap and GBARunner2. Written in C++ with devkitPro/libnds.
